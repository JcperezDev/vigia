Privacidad

Actualizado el 28 de octubre de 2026

Vigía no recoge tus datos. No hay cuentas, anuncios ni analítica.

La app

  • Trabaja en tu PC. No envía telemetría, ni lo que tienes instalado, ni nada de tu sistema.
  • Se conecta a internet solo para esto: preguntar a GitHub si hay versión nueva (se puede apagar en Configuración), bajar la actualización que aceptas y leer de GitHub los enlaces de la página «Apoya Vigía». Si pides la ISO oficial, abre la página de Microsoft.
  • Las copias de seguridad y los registros se quedan en tu PC, en %LOCALAPPDATA%\Vigia. Si desinstalas, puedes borrar esa carpeta.

Esta web

  • No usa cookies ni analítica. Solo recuerda el idioma que eliges, guardado en tu navegador. Se borra al limpiar los datos del sitio.
  • Pregunta a GitHub cuál es la última versión para mostrar el número. En esa consulta GitHub ve tu IP, como en cualquier visita.
  • La aloja Vercel, que guarda registros técnicos (IP, fecha y página) para servirla y protegerla.

Otros servicios

Las descargas y los reportes van por GitHub y las donaciones por Ko-fi. Cada uno tiene su propia política: GitHub, Ko-fi, Vercel.

Contacto

Para cualquier duda, abre un issue en GitHub.

Privacy

Updated October 28, 2026

Vigía doesn’t collect your data. No accounts, no ads, no analytics.

The app

  • It runs on your PC. It sends no telemetry, no list of what you have installed, nothing about your system.
  • It only goes online to ask GitHub whether there’s a new version (you can turn that off in Settings), download the update you accept, and read from GitHub the links on the “Support Vigía” page. If you ask for the official ISO, it opens Microsoft’s page.
  • Backups and logs stay on your PC, in %LOCALAPPDATA%\Vigia. If you uninstall, you can delete that folder.

This website

  • No cookies, no analytics. It only remembers the language you pick, stored in your browser. Clearing the site data removes it.
  • It asks GitHub for the latest version to show the number. GitHub sees your IP for that request, as with any visit.
  • It’s hosted on Vercel, which keeps technical logs (IP, time and page) to serve and protect it.

Other services

Downloads and bug reports go through GitHub, donations through Ko-fi. Each has its own policy: GitHub, Ko-fi, Vercel.

Contact

For any question, open an issue on GitHub.

Datenschutz

Aktualisiert am 28. Oktober 2026

Vigía sammelt keine Daten von dir. Kein Konto, keine Werbung, keine Analyse.

Die App

  • Sie läuft auf deinem PC. Sie sendet keine Telemetrie, keine Liste deiner Programme und nichts über dein System.
  • Ins Internet geht sie nur, um bei GitHub nach einer neuen Version zu fragen (in den Einstellungen abschaltbar), das Update zu laden, dem du zustimmst, und die Links der Seite „Vigía unterstützen“ von GitHub zu lesen. Wenn du die offizielle ISO willst, öffnet sie die Seite von Microsoft.

  • Gehostet wird sie bei Vercel, das technische Protokolle (IP, Zeit und Seite) speichert, um sie auszuliefern und zu schützen.

Downloads und Fehlerberichte laufen über GitHub, Spenden über Ko-fi. Jeder hat eigene Regeln: GitHub, Ko-fi, Vercel.
