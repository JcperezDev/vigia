## Fallos encontrados en la VM y arreglados
`4dbe8c8` install-check pedía `es.json` · `1894d15` la tarea vieja con privilegios máximos no se reconocía (XML leído con la página de códigos equivocada) y la sesión 0 se tomaba por «juego abierto» · `1af5284` el servicio se rechazaba a sí mismo como SYSTEM (error 1053) · `61a102f` reparar con un archivo abierto dejaba el servicio parado · `03ad4c4` PawnIO se daba por quitado sin mirar el resultado · `048de17` desinstalar desde el instalador dejaba la carpeta vacía · `97b9c29`/anteriores el ayudante elevado no se cerraba por inactividad · `14b506d` ventana en negro al abrir tras arrancar con Windows. · `dd36490` al actualizar, el servicio de sensores de una compilación de laboratorio no se quitaba.

## Sin probar en VM
UAC con usuario estándar (pide la contraseña de un admin; no se teclea ninguna), red cortada a mitad de descarga real (solo el corte del proceso), disco lleno, reinstalación desde Microsoft Store, Win32 con su desinstalador (no se ejecuta solo, por diseño), lectura de temperaturas reales (la VM no tiene sensores). Esto último queda para hardware físico autorizado.
