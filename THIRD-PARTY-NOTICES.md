# Componentes de terceros

Vigía usa estas piezas, cada una con su licencia:

| Componente | Para qué | Licencia |
|---|---|---|
| [LibreHardwareMonitorLib](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) | Temperaturas, relojes y sensores | MPL-2.0 |
| [Microsoft.Web.WebView2](https://www.nuget.org/packages/Microsoft.Web.WebView2) | Ventana de la interfaz | Licencia de Microsoft (BSD-style) |
| [Microsoft.Diagnostics.Tracing.TraceEvent](https://github.com/microsoft/perfview) | FPS reales (eventos ETW de Present) | MIT |
| [PawnIO 2.2.0](https://pawnio.eu) | Driver para leer los grados del procesador. Va el instalador oficial firmado, sin cambios (`drivers\PawnIO_setup.exe`); código fuente en [github.com/namazso/PawnIO](https://github.com/namazso/PawnIO) | GPL-2.0 |
| [System.Management](https://github.com/dotnet/runtime) | Consultas WMI | MIT |
| [IBM Plex Sans](https://github.com/IBM/plex) | Tipografía | SIL OFL 1.1 |
| [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) | Tipografía de números y comandos | SIL OFL 1.1 |

El logo, el fondo VigíaOS y el resto del código son propios de Vigía.
